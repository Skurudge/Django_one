# Мой учебный проект Python "Django_one"

## Описание:

Начинается работа над проектом интернет-магазина: настройка нового проекта Django_one, включая создание и регистрацию нового приложения и реализацию первых страниц с использованием шаблонов и контроллеров. По сути, это фундамент для будущего развития проекта.


Редактирование содержания проекта сторонними пользователями не предусмотрено.

## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. На данном этапе развития проекта можно ознакомиться с элементами и разработанными функциями. 

### Разработанные объекты, функции и модули:

- Настройка проекта: создана новая директория для проекта и настроено виртуальное окружение.
Инициализирован новый проект Django_one внутри этой директории.
- Создано новое приложение под названием catalog в проекте. Зарегистрировано приложение в настройках проекта.
Настроена маршрутизация для нового приложения.
- Подготовлены два HTML-шаблона: для домашней страницы home.html и для страницы с контактной информацией contacts.html. Для стилизации страниц используется Bootstrap.
- Реализованы контроллеры для отображения домашней страницы и для для отображения страницы с контактной информацией.
Настроена маршрутизация для этих контроллеров.
- Реализована форма обратной связи на странице контактов. Настроена обработка данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных.
