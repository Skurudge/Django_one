# Мой учебный проект Python "Django_one"

## Описание:

Проект представляет собой развивающийся маркетплейс "Skystore" — платформу для хранения, публикации и продажи плагинов и примеров кода. Веб-приложение построено на базе фреймворка Django с использованием архитектурного подхода CBV (Class-Based Views), СУБД PostgreSQL и стилизации интерфейса на Bootstrap. В систему интегрирована полноценная система аутентификации пользователей с кастомной моделью авторизации, контентный раздел (блог) и продвинутые механизмы валидации данных.

Редактирование содержания проекта сторонними пользователями не предусмотрено.

## Установка:

1. Клонируйте репозиторий:
   ```bash
   https://github.com/Skurudge/Django_one
   ```
2. Нанянчите переменные окружения в файле `.env` в корне проекта (укажите параметры подключения к PostgreSQL и `SECRET_KEY`).
3. Сгенерируйте и примените миграции базы данных:
   ```bash
   python manage.py makemigrations users
   python manage.py migrate
   ```
4. Наполните базу данных тестовыми материалами:
   ```bash
   python manage.py add_products
   ```

## Использование:

1. Запустите локальный сервер разработчика: `python manage.py runserver`.
2. Перейдите по адресу `http://127.0.0` в вашем веб-браузере.
3. На данном этапе развития проекта анонимным пользователям доступен только просмотр каталога. Для управления товарами необходимо пройти регистрацию и войти в систему.

### Разработанные объекты, функции и модули:

* **Кастомная система аутентификации (Приложение `users`):**
  * Создана собственная модель пользователя на базе `AbstractUser`. Авторизация переведена со стандартного `username` на электронную почту (`email`).
  * К модели добавлены кастомные поля: аватар (изображение), номер телефона и страна.
  * Реализована форма регистрации нового пользователя с обязательным подтверждением пароля (`password_confirm`) и валидацией на их совпадение.
  * Реализована форма авторизации по паре `email` и `password`.
  * *Дополнительное задание:* Разработан интерфейс редактирования профиля пользователя (`ProfileView`) с возможностью загрузки аватара и обновления контактных данных.
* **Отправка приветственных писем:**
  * Интегрирована автоматическая отправка приветственного email-сообщения пользователю сразу после успешного завершения регистрации на платформе.
* **Ограничение доступа и безопасность (Задание 3):**
  * С помощью миксина `LoginRequiredMixin` закрыт доступ ко всем контроллерам управления продуктами (детальный просмотр, создание, редактирование и удаление) для неавторизованных пользователей.
  * Общедоступной для гостей оставлена только главная страница со списком товаров.
  * Настроено динамическое меню навигации, скрывающее элементы управления и выводящее статус авторизации пользователя.
* **Архитектура на CBV (Class-Based Views):** 
  Все ключевые контроллеры приложений `catalog`, `blog` и `users` работают на классах, обеспечивая чистоту кода.
* **Интеграция Django Forms и CRUD для товаров:**
  Реализован полный цикл управления продуктами через интерфейс сайта с валидацией спам-слов, проверкой на отрицательную цену и ограничением загружаемых картинок (до 5 МБ, форматы JPEG/PNG).
* **Полноценный контентный раздел (Блог):**
  Создано приложение `blog` с автоматической фильтрацией публикаций, счетчиком просмотров и триггером email-поздравлений при достижении 100 просмотров статьи.

### Тестирование:

* Тестирование функциональности выполняется вручную через сценарии проверки ограничений доступа для анонимов, валидацию паролей при регистрации и вывод отправляемых писем в консоль разработчика.
