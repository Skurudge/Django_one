# Мой учебный проект Python "ООП"

## Описание:

Проект "OopProject" - это учебный проект на Python, содержащий последовательность выполнения домашних задач, 
начиная с раздела "4. Объектно-ориентированное программирование". 

Большая часть разработки проекта использует ООП-подход для создания своих сервисов, а также работы с данными, 
которые представляют собой сущности или объекты со своими параметрами и методами. Проработка использования классов 
и объектов на основе популярной темы e-commerce.
E-commerce  — электронная торговля, или электронная коммерция. На данном этапе разработки проекта не будет реализована 
система платежей, однако будет выполнена подготовка для того, чтобы появилось ядро для интернет-магазина. 

Редактирование содержания проекта сторонними пользователями не предусмотрено.

### Разработанные объекты, функции и модули:
- Определен [class Product](src/product.py) со следующими свойствами: название (name), 
описание (description), цена (price), количество в наличии (quantity). Добавлена инициализация так, 
чтобы каждый параметр был передан при создании объекта и сохранен. Создан класс-метод 
new_product, который принимает на вход параметры товара в словаре и возвращать созданный объект класса 
Product. Для данного метода реализована проверка наличия такого же товара схожего по имени. В случае если товар 
уже существует, складывается количество в наличии старого товара и нового. При конфликте цен выбирается та, 
которая является более высокой. Атрибут цены сделан приватным и добавлены геттер и сеттер. 
В сеттере реализована проверка: в случае если цена равна или ниже нуля, выводится сообщение в консоль 
“Цена не должна быть нулевая или отрицательная”, при этом новая цена не устанавливается. Для класса 
добавлено строковое отображение посредством магического метода __str__ в следующем виде:
"Название продукта, 80 руб. Остаток: 15 шт.", а также возможность сложения двух продуктов посредством
магического метода __add__, когда выводится общая стоимость двух продуктов на складе. При этом метод __add__ 
доработан так, чтобы можно было складывать товары только из одинаковых классов продуктов. То есть новая функциональность 
не даёт возможность сложить "смартфон" и "траву газонную" (вместо этого выдаётся ошибка TypeError).
- В [class Product](src/product.py) добавлено условие: при создании товара (метод __init__) с нулевым количеством 
вызывается исключение ValueError с сообщением "Товар с нулевым количеством не может быть добавлен". 
При этом прерывается выполнение программы. 
- Определен [class Category](src/category.py) со следующими свойствами: название (name), 
описание (description), список товаров категории (products). Добавлена инициализация так, 
чтобы каждый параметр был передан при создании объекта и сохранен. Добавлены два атрибута класса. 
Доступ к этим атрибутам есть у каждого объекта класса, в них хранится общая информация для всех объектов. 
Эти атрибуты хранят в себе количество категорий и количество товаров. Атрибуты класса заполняются автоматически
при инициализации нового объекта. Для добавления товаров в категорию реализован специальный метод 
add_product() в классе, в который можно передавать объект класса Product и уже его записывать 
в приватный атрибут списка товаров. При этом, метод add_product() доработан таким образом, что нет возможности добавить 
вместо продукта или его наследников любой другой объект. Реализован геттер, который выводит список товаров в виде строк 
в заданном формате. Для класса добавлено строковое отображение посредством магического метода __str__ в следующем виде:
"Название категории, количество продуктов: 200 шт.", когда выводится общее количество товаров категории на складе.
- В [class Category](src/category.py) реализован метод [middle_price](src/category.py), который подсчитывает 
средний ценник всех товаров. С помощью блока исключений try/except обработан случай, когда в категории 
нет товаров и сумма цен товаров будет делиться на ноль. В этом случае [middle_price](src/category.py) возвращает ноль.
- Определен [class ProductsIterator](src/iter_products.py) с помощью которого можно перебирать 
товары одной категории, например в цикле for. Для этого новый класс принимает на вход объект класса категории и 
производит итерацию по товарам, которые хранятся в данной категории, применяя магические методы __iter__ и __next__. 
- Определен [class Smartphone](src/smartphone.py) который наследует классу [class Product](src/product.py) 
со следующими дополнительными свойствами: производительность (efficiency), модель (model), объем встроенной памяти 
(memory), цвет (color). 
- Определен [class LawnGrass](src/lawngrass.py) который наследует классу [class Product](src/product.py) 
со следующими дополнительными свойствами: страна-производитель (country), срок прорастания (germination_period), 
цвет (color).
- Реализована загрузка данных по категориям и товарам из файла [JSON](data/products.json). 
Для этого разработана функция [read_json_data](src/utils.py), которая загружает данные из файла. 
И разработана функция [create_objects_from_json](src/utils.py), которая создает объекты классов.
- Создан базовый абстрактный класс с именем BaseProduct[class BaseProduct](src/base_product.py), который 
является родительским для класса продуктов. Классы [class Smartphone](src/smartphone.py) 
и [class LawnGrass](src/lawngrass.py) остаются наследниками класса Product и тем самым наследуют все свойства 
абстрактного класса.
- Реализован класс-миксин [class PrintMixin](src/print_mixin.py), который при создании объекта будет печатать 
в консоль информацию о том, от какого класса и с какими параметрами был создан объект.
- Создан класс [class OrderProduct](src/order_product.py) с указанием товара, который был куплен, 
количество купленного товара, а также итоговой стоимости. 
- Для классов [class OrderProduct](src/order_product.py) и [class Category](src/category.py) выделено общее свойство, 
вынесенное в их общий абстрактный класс [class BaseCategory](src/base_category.py).
- Создан класс исключения [class ZeroQuantity](src/exceptions.py), который отвечает за обработку событий, 
когда в «Категорию» (внесено условие обработки исключения в [Category.add_product](src/category.py)) или 
«Заказ» (внесено условие обработки исключения в [OrderProduct.__init__](src/order_product.py)) добавляется товар 
с нулевым количеством. Исключение вызывает и выводит соответствующее сообщение. В случае успешного добавления товара 
выводится сообщение о том, что товар добавлен. И также при любом исходе выводится сообщение, что обработка добавления 
товара завершена.
- Весь имеющийся код в файле [main.py](main.py) запускается без ошибок.
