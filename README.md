# Мой учебный проект Python "Django_one"

## Описание:

Проект представляет собой развивающийся маркетплейс "Skystore" — платформу для хранения, публикации и продажи плагинов и примеров кода. Веб-приложение построено на базе фреймворка Django с использованием архитектурного подхода CBV (Class-Based Views), СУБД PostgreSQL и стилизации интерфейса на Bootstrap. В систему интегрированы полноценный контентный раздел (блог) и продвинутые механизмы валидации пользовательских данных.

Редактирование содержания проекта сторонними пользователями не предусмотрено.

## Установка:

1. Клонируйте репозиторий:
   ```bash
   https://github.com/Skurudge/Django_one
   ```
2. Настройте переменные окружения в файле `.env` в корне проекта (укажите параметры подключения к PostgreSQL и `SECRET_KEY`).
3. Примените миграции базы данных:
   ```bash
   python manage.py migrate
   ```
4. (Опционально) Наполните базу данных тестовыми материалами:
   ```bash
   python manage.py loaddata catalog_data.json
   ```
   или запустите кастомную команду:
   ```bash
   python manage.py add_products
   ```

## Использование:

1. Запустите локальный сервер разработчика: `python manage.py runserver`.
2. Перейдите по адресу `http://127.0.0` в вашем веб-браузере.
3. На данном этапе развития проекта можно ознакомиться с элементами, управлять каталогом товаров и публиковать статьи в блоге.

### Разработанные объекты, функции и модули:

* **Архитектура на CBV (Class-Based Views):** 
  Все ключевые контроллеры приложения `catalog` и `blog` переведены с функций на высокоуровневые классы (`ListView`, `DetailView`, `CreateView`, `UpdateView`, `DeleteView`), что обеспечивает чистоту и масштабируемость кодовой базы.
* **Каталог товаров и Пагинация:** 
  Реализована главная страница со списком продуктов, поддерживающая постраничный вывод (пагинация по 6 товаров на страницу). Настроена обрезка длинных описаний с помощью встроенных фильтров шаблонов.
* **Интеграция Django Forms и CRUD для товаров:**
  Реализован полный цикл управления продуктами (создание, просмотр, редактирование и удаление) через интерфейс сайта с использованием модуля `django.forms`.
* **Продвинутая валидация и защита от спама:**
  * Внедрен жесткий фильтр названий и описаний продуктов на основе списка запрещенных слов (казино, крипта, биржа, бесплатно и др.) с полным игнорированием регистра символов.
  * Реализовано автоматическое косметическое приведение названий товаров к нижнему регистру (строчным буквам) при сохранении в базу данных.
  * Добавлена валидация поля цены, полностью блокирующая ввод отрицательных значений.
  * *Дополнительное задание:* Настроена строгая валидация загружаемых изображений товаров — поддерживаются только форматы JPEG/PNG, а максимальный размер файла ограничен 5 МБ.
* **Полноценный контентный раздел (Блог):**
  Создано изолированное приложение `blog` со своей моделью блоговой записи (`BlogPost`), админ-панелью и CRUD-архитектурой. 
  * На уровне контроллеров настроена автоматическая фильтрация: в общем списке отображаются только статьи с положительным признаком публикации.
  * Переопределен метод `get_object` для динамического увеличения счетчика просмотров при каждом открытии статьи.
  * Настроено автоматическое перенаправление пользователя на страницу прочитанной статьи после её успешного редактирования.
  * *Дополнительное задание:* Интегрирована система email-уведомлений, отправляющая поздравление на почту администратора, как только статья достигает ровно 100 просмотров.
* **Управление данными и фикстуры:**
  Написана кастомная консольная команда `add_products` для автоматической очистки и первичного наполнения базы данных. Подготовлена корневая JSON-фикстура для быстрой миграции данных.

### Тестирование:

* Тестирование функциональности на данном этапе развития проекта выполняется вручную через интерактивные сценарии валидации форм, проверку триггеров ошибок в браузере и логирование операций в консоль.
