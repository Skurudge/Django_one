## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. На данном этапе развития проекта можно ознакомиться с элементами и разработанными функциями. 

### Разработанные объекты, функции и модули:

- В [class Category](src/category.py) реализован метод [middle_price](src/category.py), который подсчитывает 
средний ценник всех товаров. С помощью блока исключений try/except обработан случай, когда в категории 
нет товаров и сумма цен товаров будет делиться на ноль. В этом случае [middle_price](src/category.py) возвращает ноль.
- Определен [class ProductsIterator](src/iter_products.py) с помощью которого можно перебирать 
товары одной категории, например в цикле for. Для этого новый класс принимает на вход объект класса категории и 
производит итерацию по товарам, которые хранятся в данной категории, применяя магические методы __iter__ и __next__. 
- Определен [class Smartphone](src/smartphone.py) который наследует классу [class Product](src/product.py) 
со следующими дополнительными свойствами: производительность (efficiency), модель (model), объем встроенной памяти 
(memory), цвет (color). 

### Тестирование:

- Разработаны тесты, используя pytest и применяя [фикстуры](tests/conftest.py).

- Разработаны тесты [test_product_init_product_one/two](tests/test_product.py) проверяющие корректность инициализации объектов 
класса [Product](src/product.py). Добавлено тестирование новой функциональности, в том числе методов __str__, __add__. Добавлено
тестирование класс-методов: создание объекта Продукт из словаря [test_product_from_dict](tests/test_product.py), 
добавление нового продукта в список в случае, когда продукт уже есть в списке (с обновлением цены и 
сложением количества) [test_update_or_add__update](tests/test_product.py), и вариант, когда продукта нет в списке
и он добавляется к существующему списку [test_update_or_add__add](tests/test_product.py).
- В тестирование класса [Product](src/product.py) добавлена проверка, что продукт с нулевым количеством не может быть
добавлен. При этом вызывается исключение ValueError с сообщением: 
"Товар с нулевым количеством не может быть добавлен".
